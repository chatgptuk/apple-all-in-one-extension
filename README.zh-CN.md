# Apple All-In-One

这是一个独立开源的 Chromium 扩展，把 Apple 密码、通行密钥、动态验证码和 iCloud+ 隐藏邮件地址整合到一个界面中。

> [!IMPORTANT]
> **请先看清楚：这个项目目前适合在 macOS 上自行构建、侧载使用，不是可以直接提交 Chrome 应用商店的成品。** 为了让 macOS 的原生密码辅助程序接受连接，密码模块保留了 Apple 官方扩展所使用的公开 Manifest 公钥，因此会生成相同的扩展 ID。这样做有三个直接后果：官方扩展不能与本项目同时启用；当前构建不适合直接上架商店；技术上能够连接也不等于获得了 Apple 的发布或品牌授权。

本项目未经 Apple Inc. 认可、赞助或授权，也与 Apple Inc. 没有关联。文中出现 Apple、iCloud、iCloud+、Apple 密码等名称，仅用于说明兼容对象和所调用的服务。

**当前版本：** 1.2.20<br>
**项目仓库：** https://github.com/chatgptuk/apple-all-in-one-extension

## 这个项目适合谁

如果你符合下面这些情况，可以尝试本项目：

- 在 macOS 上使用 Chrome、Edge 等 Chromium 浏览器；
- 平时把账号、密码和动态验证码保存在 Apple 密码中；
- 已订阅 iCloud+，并在使用隐藏邮件地址；
- 能接受用命令构建扩展，再通过“加载已解压的扩展程序”进行侧载；
- 能接受 Apple 或浏览器更新后，非公开接口可能临时失效。

如果你准备把它当作 Apple 官方产品宣传、提交 Chrome 应用商店、进行企业批量部署或商业销售，当前版本并不合适。README 后面单独说明了原因和建议的处理方式。

## 功能概览

### Apple 密码

- 连接 macOS 自带的 `com.apple.passwordmanager` 原生辅助程序。
- 沿用 Open Passwords 的 SRP 握手和 AES-GCM 加密查询协议。
- 查询、填充、保存和更新密码。
- 优先显示网站主机名完全匹配的登录项；没有完全匹配时，再显示相关域名的结果。
- 支持通行密钥桥接，也可以关闭网页静默弹出的条件式通行密钥建议。
- 查询 Apple 密码中保存的动态验证码，并在校验网页来源和 frame 后进行填充。
- 解密后的敏感数据只留在扩展内存中；原生会话结束后会自动清理。

在扩展主界面点击一条已保存登录时，会同时填充当前网页并展开详情。详情中会显示用户名、遮罩密码、网站以及是否存在验证码；密码只有在你主动点击后才会显示。如果该账号还保存了验证码，需要再点击一次**显示验证码**。这是因为密码和验证码是两次独立的原生读取，macOS 可能分别要求 Touch ID，扩展不能安全地把两次系统授权强行合并。

单独点击验证码条目时，扩展会用同一次经 Touch ID 授权的读取结果完成网页填充并展开验证码详情，不会为了显示详情再重复验证一次。

### iCloud+ 隐藏邮件地址

- 创建、预留、填充、搜索、启用、停用和删除隐藏邮件地址。
- 地址列表使用两分钟会话缓存：再次打开标签时会先显示现有列表，缓存过期后在后台静默更新，不会每次都让页面卡在加载中。
- 删除仍在使用中的地址时，会自动执行 `停用 → 删除`。
- 支持多选、批量停用和批量删除；部分项目失败时，只保留失败项供重试。
- 根据标签和网站信息识别关联域名，并通过 Chromium 的网站图标能力显示图标；解析失败时使用稳定的字母占位图。
- “最后收到邮件”时间缓存 24 小时，也可以手动强制刷新。
- 只有点击地址详情里的**检查**后才读取近期 iCloud 邮件预览；关闭弹窗后，主题、发件人、预览和验证码都会从内存中丢弃。
- 在本地从近期邮件主题和预览中识别可能的 4–8 位验证码。

隐藏邮件地址功能使用浏览器里已经登录的 iCloud.com 会话。扩展不会要求你在扩展中输入 Apple 账户密码，也不会把 Apple 密码模块的原生会话密钥交给 iCloud 模块。

### 网页内选择器与私密注册

- 当前网站有已保存登录时，只显示登录项，并把完全匹配的项目排在最前面。
- 已有可用登录时，不再混入“私密注册”等无关操作。
- 当前网站没有已保存登录时，**私密注册**可以复用已有隐藏地址；找不到匹配地址时，才会在你确认后创建新地址并准备强密码。
- 检测到网页上的“使用 Apple 登录”按钮时，只有你主动选择后才会触发它。
- 创建隐藏邮件地址仍可通过输入框右键菜单使用，不在网页选择器中重复显示同一种功能。

仅仅聚焦邮箱输入框，扩展**不会**自动创建地址。完整流程是：选择**创建隐藏邮件地址** → 查看候选地址 → 点击**使用** → 预留并填入当前输入框。这样不会因为网页中出现一个邮箱框，就产生一堆没有真正使用的地址。

## 使用条件与安装方法

### 使用条件

- Apple 密码原生集成：macOS 15.4 或更高版本
- Chrome、Edge 等 Chromium 浏览器
- Node.js 20 或更高版本
- 隐藏邮件地址：有效的 iCloud+ 订阅
- 隐藏邮件地址和近期邮件：浏览器中已经登录 iCloud.com

### 构建扩展

在项目目录运行：

```bash
npm install
npm run typecheck
npm run build
```

然后按下面的步骤安装：

1. 打开 `chrome://extensions`。
2. 开启右上角的**开发者模式**。
3. 停用或移除 Apple 官方密码扩展，以及之前加载的 Open Passwords。它们与本项目使用同一个固定扩展 ID，不能同时启用。
4. 点击**加载已解压的扩展程序**，选择本项目生成的 `build/` 文件夹。
5. 如果这台电脑以前没有配置过原生辅助程序，运行 `native/install.sh`，完全退出 Chrome，再重新打开。
6. 确认整合扩展正常后，建议停用旧的独立隐藏邮件地址扩展，避免重复右键菜单和重复请求。

开发监听模式：

```bash
npm run watch
```

## 启动、解锁和会话

- 安装扩展或启动浏览器时，不会自动检查 iCloud，也不会提前连接 Apple 密码。
- 只有真正打开或使用对应功能时，密码模块和隐藏邮件地址模块才会启动。
- Chromium 正在唤醒 Manifest V3 Service Worker 时，弹窗会对后台消息做短暂重试。
- Apple 密码的六位数访问码对应当前原生会话。保活闹钟可以减少 Service Worker 被挂起造成的重连，但无法保证真正退出并重启浏览器后仍然保持解锁。
- 隐藏邮件地址可以自动重新检查浏览器现有的可信 iCloud 会话。如果 Apple 要求重新登录、双重认证或确认设备信任，扩展会停止并引导你打开 iCloud.com，不会尝试绕过验证。

## 语言切换

主弹窗、设置页、安装指南、网页内选择器、右键菜单和通知均支持英文与简体中文。

- 默认选择**跟随浏览器**，通过 `chrome.i18n.getUILanguage()` 判断语言。
- 点击扩展主界面右上角的地球按钮，可以立即切换中文或英文。
- 也可以前往**设置 → 通用 → 语言**修改同一个选项。

## 隐私与安全边界

### 密码模块

- 只通过 `com.apple.passwordmanager` 与 macOS 原生辅助程序通信。
- 先进行 SRP 质询，再通过 AES-GCM 加密通道查询。
- 特权弹窗消息会在后台进行校验。
- 填充前会检查目标 frame 和网页来源。
- 明文密码及临时缓存只保存在扩展内存中，并跟随原生会话清理。

### iCloud 模块

- 使用浏览器已有的 iCloud.com Cookie/会话，不收集 Apple 账户密码。
- 不读取密码模块的原生会话密钥或已经解密的 Apple 密码。
- 近期邮件只扫描数量受限的收件箱会话，不扫描垃圾邮件、废纸篓和已删除邮件。
- 只持久化历史“最后收到邮件”时间；邮件正文、主题、预览和识别出的验证码不会写入扩展存储。

这些设计可以减少敏感数据暴露，但不能把 Apple 的非公开协议变成受官方支持的公共 API。

## 项目来源：哪些是上游，哪些是本项目新增

本项目主要整合了两个开源项目：

1. [Open Passwords](https://github.com/ManiForoughi2/open-passwords) 提供 Apple 密码原生通信、加密协议、密码查询与保存流程、通行密钥组件、OTP 输入框排除逻辑，以及最初的安全网页内选择器。Apple All-In-One 自行实现了已保存验证码的发现、按需读取、主界面/网页选择建议和带来源校验的填充；这些 OTP/验证码管理功能并非由 Open Passwords 提供。
2. [iCloud Hide My Email Browser Extension](https://github.com/dedoussis/icloud-hide-my-email-browser-extension) 提供原始扩展框架和隐藏邮件地址私有 Web 服务集成。重新设计的地址管理器、两分钟列表缓存、网站识别、近期邮件活动与预览、直接删除、批量管理、私密注册和整合界面，是后续项目工作。

## 已知限制

- Apple 密码原生集成只面向 macOS 上的 Chromium 浏览器。
- Firefox 可以构建隐藏邮件地址部分，但没有相同的 Apple 密码原生辅助路径。
- 使用相同扩展 ID 时，Apple 官方密码扩展必须停用。
- Apple 或浏览器升级后，原生协议和 iCloud 私有接口可能失效。
- 近期邮件功能仅适用于转发到 `@icloud.com`、`@me.com` 或 `@mac.com` 的隐藏地址。
